# ドコモ 簡易見積ツール（みんなのスマホ相談所）

iPad の Safari で開いて使う見積ツール。ボタンを押すだけで金額が入り、「印刷（A4縦）」で見積書を印刷できる。

## ファイル
| ファイル | 中身 | 更新 |
|---|---|---|
| index.html | 画面と計算 | 手で直す |
| data.js | 料金プラン・割引・オプション・初期費用 | 手で直す（料金改定のとき） |
| devices.js | 機種代金（オンラインショップ価格） | **毎朝自動** |
| updates.js | 自動チェックの結果（お知らせ・新プラン・料金変更） | **毎朝自動** |
| update/daily_update.py | 自動更新プログラム | — |
| .github/workflows/daily-update.yml | 毎朝5時に自動更新を動かす設定 | — |

## 毎朝の自動更新
- 毎日 5:00 にドコモ公式「おてがる料金シミュレーション」（＝ドコモオンラインショップの販売価格）を読み、全機種の価格を取り直す。
- 新しい機種・販売終了・価格変更・新しい料金プランは、画面上部の「📢 ドコモの更新情報」に2週間表示される。
- 新しい料金プランは自動でプランのボタンに「新プラン」として追加される（割引の条件は公式サイトで確認して、必要なら data.js に正式登録する）。
- 取得に失敗した日は前日のデータのまま表示し、画面上部に赤い注意が出る。2日以上止まった場合も赤い注意が出る。
- 手動で今すぐ更新したいとき：GitHub の Actions →「毎朝の料金・機種チェック」→ Run workflow。

## 自動では入らないもの（手で data.js を直す）
- 割引・キャンペーンの金額や条件（年齢の割引、ハーティ割引、みんなドコモ割 など）
- オプション（あんしんパック、コネクトα 等）や事務手数料の金額
